NaOS v0.1.0.

The first frozen release: a bootable, usable system. Own UEFI bootloader and kernel, shell, files, multitasking, USB keyboard, networking and three storage drivers — zero prebuilt OS code.

Highlights

01

39 plain-English commands

Files, system, network, power — with history, scrollback, font sizes, output redirect and a themeable prompt.

02

AHCI · NVMe · ATA + FAT32 + live RAM disk

One block layer, writable FAT32, long filenames. Boots from SATA, NVMe — or straight off the ISO with files.

03

fork() with CoW

Ring-3 programs, private address spaces, preemptive scheduler, copy-on-write fork, file syscalls.

04

TCP/IP + DHCP + DNS + updater

E1000 driver, ARP/ping, UDP sockets, DHCP lease at boot, DNS, TCP client with HTTP fetch and hash-verified update.

05

PS/2 + USB HID

Polled XHCI stack with hotplug rescan, classic PS/2 fallback, PC-speaker beeps.

06

ISO export + auto-boot

El Torito UEFI image, shell auto-boot fallback, Rufus/DD-mode guide for real hardware.

03/

Run it

Inside this folder. One-time host setup is in the README. Artifact sizes: BOOTX64.EFI 15,656 B · KERNEL.ELF 150,848 B · RAMDISK 40MiB · DATA.NAFS 61,952 B · ESP 64MiB · ISO ~67.7MiB.

export PATH=/opt/cross/bin:$PATH
./tools/check.sh   # verify tools + OVMF
make all && make esp
make run           # → NaOS> shell
make run-iso       # needs xorriso: boot the ISO itself

05/

How v0.1.0 was built

Boot + shell — custom BOOTX64.EFI, GOP console, NaOS> prompt
Memory — own PML4 paging, PMM, kmalloc heap
Files — ATA → AHCI DMA → writable FAT32 + long names
Multitasking — ring-3 tasks, syscalls, fork() with copy-on-write
Hardware — PCI scan, XHCI USB keyboard, PC speaker, ACPI power
Network — E1000, ARP/ping, UDP/DHCP/DNS, TCP client + updater
NVMe + live ISO — polled driver in the block layer; 40MB live RAM disk, boots anywhere
