Capabilities

Every line below the firmware is ours — bootloader, kernel, drivers, filesystem, scheduler, network stack.

01

Own UEFI bootloader

Custom BOOTX64.EFI in C: GOP framebuffer, ELF64 parsing, one-shot ExitBootServices, clean handoff — plus a shell auto-boot fallback.

02

Plain-English shell

A NaOS> prompt with 39 commands, history, scrollback, font sizes, output redirect and a themeable prompt.

03

Real storage

AHCI, NVMe and ATA under one block layer, writable FAT32, long filenames — and a 40MB live RAM disk, so the ISO boots with files anywhere.

04

Multitasking + fork

Ring-3 tasks with private address spaces, preemptive scheduler, syscalls, copy-on-write fork(), disk-loaded ELF programs with file I/O.

05

TCP/IP networking

E1000 driver with ARP, ping, UDP sockets, DHCP, DNS and a TCP client — fetch pages over HTTP, update pulls verified downloads.

06

USB HID keyboard

Polled XHCI stack with hotplug rescan next to the classic PS/2 driver. PC-speaker beeps included.

Build it

Windows + MSYS2 UCRT64, QEMU, and the /opt/cross toolchain. Full setup in the version README.

# inside versions/v0.1.0
export PATH=/opt/cross/bin:$PATH
./tools/check.sh  # verify every tool + OVMF
make all           # BOOTX64.EFI + KERNEL.ELF
make esp           # 64M FAT ESP image
make run           # QEMU + OVMF → NaOS> shell

  No build? Grab NaOS v0.1.0.iso from the release, boot it with Rufus (DD mode, Secure Boot off) — or browse the code online.
